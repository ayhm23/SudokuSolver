Generated by `python scripts/analyse_cells.py` (data: `noise_flips.csv`). Each noisy image is compared with the clean render of the same puzzle index (same puzzle, same font, same layout; only the noise differs). Cell counts are over all 81 cells, using the CNN argmax. *wrong -> right*: misread in the clean render, read correctly in the noisy one; *right -> wrong*: the reverse; *wrong -> other wrong*: misread in both, as different digits. The last two columns compare maxsat_weighted's full-grid outcome on the pair (`outputs/e2e/e2e_final_noise_cnn.csv`). rotate 1.0 has 99 images (one grid not found).
