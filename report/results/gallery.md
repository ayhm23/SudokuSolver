# Gallery: real successes and failures

Generated by `python scripts/make_gallery.py`. Every example is a real image from an existing evaluation run (synthetic `test_final`, seed 40000; or the public wichtounet v2 real photos). Nothing was hand-made or edited. Each image was chosen by a fixed rule (below and in the script), **re-run** exactly as `scripts/run_e2e.py` ran it, and kept only if the re-run reproduced the CSV row (status, correct, n_misreads, misreads_corrected, correct_overridden) for every method shown. The CSVs do not store override explanations; the explanation text below is the system's output from that re-run (`reasoning/explain.py`, `describe_override`), copied verbatim. Solve times in the CSV tables are from the original run.

Figures: `report/figures/gallery/<name>.{png,pdf}` (300 dpi). Panels: input with the detected grid (synthetic: green = true outline) | CNN argmax with its top-class probability (red dashed box = differs from ground truth) | final grid of the method named in the panel title (green cell = override that fixed a misread, red cell = harmful override, red digit = wrong vs the true solution).

## (b) MaxSAT recovers a missed digit (given read as empty)

Rule: the solver put back a true digit the CNN read as EMPTY. With plain MAP (maxsat_weighted) this cannot happen: an empty reading adds no constraint, so keeping it is never more expensive (reasoning/explain.py). It can only happen with maxsat_unique, which rejects readings that leave the puzzle ambiguous.
